# DUSTLINE 3.0

Браузерный командный 3D-шутер от первого лица. До 32 игроков на одном сервере.

## Запуск
Node.js 20+: npm install, затем npm start. Открыть http://localhost:3000.
Проверки: npm test.

## Игра
Две автоматически сбалансированные команды. При выходе игроков баланс восстанавливается. Командный бой с возрождением, общий счёт и индивидуальные убийства/смерти. Урон союзникам выключен.
12 моделей оружия: AK-47, M4A1, FAMAS, Glock, Desert Eagle, MP5, P90, Nova, XM1014, AWP, Scout, Negev; плюс нож.
Осколочная, дымовая и световая гранаты. Дым скрывает обзор, вспышка временно ослепляет, стены блокируют взрыв и пули. Магазины, перезарядка, повышенный урон в голову.
Оригинальная пустынная карта Dust Courtyard с A/B, центром, боковыми проходами и ящиками. Это прототип в стиле тактических шутеров, а не точное воспроизведение CS или Mirage. Режим закладки бомбы и экономика не реализованы.

## Управление
WASD — ходить; мышь — обзор; ЛКМ — стрелять; ПКМ — прицел; Space — прыжок; R — перезарядка; G — бросок; H — следующий тип гранаты; 1/2/3 — основное/пистолет/нож; B — выбор оружия; Tab — счёт; V — освободить мышь; повторный клик по игре — захватить мышь. Нажать на карту, чтобы захватить мышь. Для захвата мыши нужен обычный браузер с поддержкой Pointer Lock; стрелки влево/вправо также поворачивают камеру.

## Производительность
Нет динамических теней, постобработки и лута. Геометрия карты объединена по материалам; персонажи рисуются пакетами InstancedMesh. Общая геометрия, материалы и пулы эффектов. Ограниченное разрешение с автоматическим снижением при низком FPS. Сервер считает симуляцию 30 раз/с и отправляет один общий сериализованный снимок 15 раз/с. Движение локального игрока предсказывается, другие игроки сглаживаются. Вкладка в фоне прекращает рендер. FPS зависит от компьютера, графического ускорения браузера и активности вкладки.

## Размещение
Один Node Web Service, npm install / npm start, переменная PORT от хостинга. render.yaml использует free. Данные хранятся в памяти и сбрасываются при перезапуске. Бесплатный Render засыпает после простоя; первый запуск может занять минуту. Прототип рассчитан на ПК с клавиатурой и мышью.


## Графика и обратная связь
Мягкое освещение, процедурные текстуры, запечённые тени на земле, окна, навесы и детали дворов. Различимые модели оружия, руки и перезарядка. Форма двух команд, снаряжение, лица с глазами и анимация ног. Отдельная камера оружия предотвращает пересечение со стенами. Подтверждённый сервером урон: маркер попадания, число урона, отметка головы, краткая подсветка цели и лента убийств.

Движение использует нумерованные команды и подтверждения сервера, локальное предсказание и повтор неподтверждённых команд. Запасы патронов сохраняются при переключении. Настройки графики, звука и мыши запоминаются. Сбалансированная графика ограничивает кадр 1,5 млн пикселей, быстрая — 850 тыс.; качество адаптируется при длительном падении FPS.


## Контейнер и бесплатное облачное размещение
Dockerfile запускает Node.js 24 от пользователя node. Сборка: docker build -t dustline .; запуск для проверки: docker run --rm -p 3000:3000 dustline.
Для Northflank выбрать бесплатный Sandbox, один combined service из репозитория, Dockerfile в корне и публичный HTTP-порт 3000. WebSocket использует тот же адрес и порт. Одна реплика нужна для общей арены: состояние матча хранится в памяти одного процесса. Перед запуском проверить, что сервис укладывается в бесплатные лимиты, без платного тарифа и платёжной карты. Доступность выданного адреса из России нужно проверить у игроков.
